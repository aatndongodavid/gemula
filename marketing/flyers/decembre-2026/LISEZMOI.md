# Flyers de décembre 2026

Trois visuels au format Instagram (4:5).

| Fichier | Message | Usage |
|---|---|---|
| `01-bon-mois-decembre` | « Bon mois de décembre », l'équipe devant un grand 12 | Publication du 1er décembre |
| `02-bilan-on-attend-toujours` | « 31 décembre approche… on attend toujours » : formations Excel et Power BI | Prospection entreprises |
| `03-demarrez-2027` | « Démarrez 2027 avec une équipe prête » : diagnostic gratuit | Prospection entreprises, statut WhatsApp |

- `*.jpg` : 1080 × 1350, prêt pour les réseaux sociaux.
- `*-hd.jpg` : 2160 × 2700, pour l'impression ou un affichage grand format.

## Modifier un flyer

Chaque flyer est une page HTML (`01-…html`, etc.) avec ses images dans `assets/` (photos détourées, logo, polices). Ouvrez-la dans un navigateur pour la voir, modifiez le texte dans le fichier, puis regénérez l'image avec une capture d'écran à 1080 × 1350 (par exemple avec Playwright, `deviceScaleFactor: 2` pour la version HD).

Les photos sont celles de l'équipe Gemula, détourées automatiquement.

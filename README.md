# Gemula

Site du collectif étudiant Gemula — Data, IA, logiciel, design.
Construit avec **Astro** + **Tailwind CSS**.

---

## Stack

- **Astro 5** — framework de site statique
- **Tailwind CSS 3** — design system
- **TypeScript** — typage strict
- **Astro Content Collections** — gestion du contenu éditorial (Markdown + validation)

---

## Installation locale

```bash
npm install
npm run dev
